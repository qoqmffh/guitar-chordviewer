# 기타 코드 지판 뷰어

기타 지판 위 트라이어드/4화음 위치, 탑노트 기준, 포지션 묶기 기능을 제공하는 인터랙티브 다이어그램.

순수 HTML/CSS/JS 단일 파일로 동작하며 서버나 빌드 과정이 필요 없습니다.

## 실행 방법

- `index.html` 파일을 브라우저로 열면 바로 실행됩니다.
- 또는 GitHub Pages로 배포된 링크로 접속: (배포 후 여기에 URL 추가)

## 기능

- 보기 모드 3가지: 전체 지판 / 탑노트 기준 / 포지션 묶기
- 루트음 12개 (샵 표기)
- 코드 종류 8개: 메이저·마이너 트라이어드, 도미넌트7·메이저7·마이너7·하프디미니쉬7·디미니쉬7·어그먼트7
- 추천 그립 자동 계산 (가장 좁은 포지션)

## 알려진 미구현 사항

- 플랫(b) 표기 없음 (항상 샵으로 표시)
- 인버전 선택 불가 (가장 좁은 포지션만 자동 계산)
- 포지션 묶기 결과 페이지네이션 없음 (최대 8개까지만 표시)
- 탑노트 모드 + 포지션 묶기 동시 사용 불가
- 오디오 재생 없음
- 설정 저장 없음 (새로고침 시 초기화)
