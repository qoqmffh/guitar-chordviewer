board-labs

기타 코드, 외우지 말고 지판에서 보세요

코드 이름만 보고 손 모양이 바로 안 떠오를 때, board-labs 코드 페이지에서 코드 하나를 고르면 6줄 지판 위에 어느 프렛 어느 줄을 눌러야 하는지 즉시 표시됩니다. 통기타로 흔히 배우는 바레코드·오픈코드 기본 코드부터, 코드 톤을 자유롭게 골라 보는 멜로디 보이싱까지 두 가지 방식을 지원합니다.

이런 분들에게 유용합니다

  • 이제 막 기타를 시작해서 오픈코드/바레코드 손 모양을 외우는 중인 분
  • 같은 코드를 지판 위 여러 자리에서 짚는 법(보이싱)을 찾아보고 싶은 분
  • 합주·레슨 중에 코드 하나를 빠르게 확인하고 싶은 분

기능

  • 메이저·마이너·도미넌트7·메이저7·마이너7·하프디미니시·디미니시·어그먼트 등 코드 종류별 지원
  • 바레코드는 6번줄 베이스(F·F#·G·G#·A)와 5번줄 베이스(A#·B·C·C#·D·D#·E)로 실제 통기타 교습 관례에 맞춰 표시
  • 추천 그립(운지) 목록 제공
